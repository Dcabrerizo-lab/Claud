# Vergleich mit echten Bescheiden (für Tester)

Der wichtigste Test für SoLo ist der Vergleich mit dem, was ein Amt wirklich entschieden hat. Bitte nur mit **geschwärzten**
Bescheiden und nur mit Einverständnis der betroffenen Person. Namen, Anschrift, Geburtsdatum, Aktenzeichen und Kontodaten schwärzen.

## So geht es
1. In SoLo genau die Angaben eintragen, die zum Zeitpunkt des Bescheids galten (Einkommen, Miete, Haushalt, Vermögen).
2. Die Tabelle unten ausfüllen (eine Zeile je Bescheid) und an das SoLo-Team schicken. Keine Bescheid-Fotos mit lesbaren persönlichen Daten.

| Nr. | Leistung | Monat/Jahr des Bescheids | Bundesland | Haushalt (Erw./Kinder mit Alter) | Bewilligt? (ja/nein/teilweise) | Betrag laut Bescheid (€/Monat) | SoLo: Einstufung | SoLo: Betrag/Spanne | Abweichung, Begründung laut Bescheid |
|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | |
| 2 | | | | | | | | | |

## Was wir daraus machen
- Liegt der Bescheid außerhalb der SoLo-Spanne, prüfen wir Rechnung und Prüfliste (`docs/PRUEFLISTE.md`) und ergänzen einen Fall-Test.
- Abweichungen wegen Dingen, die SoLo bewusst nicht rechnet (angemessene Miete, Selbstständigkeit, Wohneigentum), sammeln wir als Hinweis für die App.
